The four physical conditions each have three execution folders:

- flat, nominal 1.145 m: `1.145`, `1.145-2`, `1.145-3`;
- raised 0.01 m, nominal 1.145 m: `0.01m,1.145`, `...-2`, `...-3`;
- flat, nominal 1.28 m: `1.28`, `1.28-2`, `1.28-3`;
- raised 0.01 m, nominal 1.28 m: `0.01m,1.28`, `...-2`, `...-3`.

These folder suffixes are execution/case identifiers, not independent training
seeds unless a separate manifest proves distinct training runs.
