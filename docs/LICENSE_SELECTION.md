# Code and data licence decision before release

The repository currently has **no grant of reuse rights**. A public GitHub
repository without a licence can be viewed and forked under GitHub's terms, but
third parties do not receive the normal permissions to reuse, modify, or
redistribute the work. The authors should make two explicit, approved choices:

1. **Software and analysis code:** MIT is the simplest permissive option for
   this academic release. BSD-3-Clause is a close alternative if the authors
   want an explicit non-endorsement clause. Apache-2.0 is appropriate when an
   express patent licence is important.
2. **Data, processed tables, and videos:** CC BY 4.0 is the recommended default
   when reuse with attribution is desired. CC0 can be selected only if every
   rightsholder agrees to waive rights as far as legally possible.

After all authors approve the choices:

- add the complete standard code licence text as repository-root `LICENSE`;
- add `DATA_LICENSE.md` identifying exactly which directories/artifacts use
  the data licence;
- put `license` in `CITATION.cff` and the README badge/availability section;
- repeat the data licence in the DOI repository metadata and archive README;
- list any third-party checkpoints, photographs, fonts, or source data that
  are excluded from the licence; and
- confirm consent and authorship for both hardware videos and all photographs.

Do not rename this guidance file to `LICENSE`: it is a decision aid, not a
licence grant. The final licence files must contain the unmodified official
text and the approved copyright holder/year where required.
